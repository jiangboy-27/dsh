# 霓虹疾走 · NEON RUSH

一个无需任何依赖、打开即玩的单文件网页跑酷游戏。

## 运行

直接双击 `index.html`，用现代浏览器打开即可。若浏览器对 `file://` 下的本地存储有限制，也可以在当前目录启动任意静态文件服务器后访问。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 跳跃 / 二段跳 | `Space`、`W`、`↑` | 右下角「跳跃」或轻点画面 |
| 滑铲 / 空中快速下落 | `S`、`↓` | 左下角「滑铲」 |
| 暂停 / 继续 | `P`、`Esc` | 右上角暂停按钮 |
| 静音切换 | `M` | 右上角音量按钮 |

## 玩法

- 自动向右奔跑，基础速度随存活时间**线性上升**，越跑越快。
- 地面路障与高墙需要跳跃越过，红色激光闸门必须滑铲从下方通过。
- 拾取强化：
  - **减速核心**：速度降低 48%，持续 6 秒。
  - **脉冲护盾**：抵挡一次撞击，并获得短暂无敌。
  - **磁力线圈**：自动吸附附近晶片。
  - **双倍矩阵**：短时得分翻倍。
- 晶片提供额外分数；磁力状态下更容易连续收集。
- 撞击即结束，分数、距离、最高速度与晶片数量会在结算页展示。
- 最高分、最远距离、挑战次数和音效偏好保存在浏览器 `localStorage`。结算时会与本机最高纪录比对，并提示新纪录或相差分数。

## 技术

纯 HTML + CSS + Canvas 2D，无外部图片、字体或脚本依赖。程序化绘制城市、角色、粒子和音效，支持桌面与触屏布局。
